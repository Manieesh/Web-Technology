# Web Technology Lab

## Comic World Web Application

A responsive comic book store web application developed for the Web Technology Laboratory.

### Experiments Overview

- **Experiment 3:** Web page structure with comic book showcase, categories, responsive layout, and custom CSS styling.
- **Experiment 4:** Develop a Sign-In and Sign-Up Page with Navigation Bar using CSS:
  - **CSS Dropdown Navigation Bar:** Interactive dropdown under the `Home` link with navigation items (Item 1, Item 2, Item 3, Item 4) styled with CSS hover effects.
  - **Authentication Portal:** Side-by-side Sign-In and Sign-Up forms using CSS Flexbox on desktop and responsive vertical stacking on mobile devices.
  - **Form Controls:** Proper labels, input types, and placeholders for Username, Name, Email, and Password.
  - **Visual Design:** White card containers with subtle shadows and rounded corners, comic superhero background image, and styled blue buttons with hover effects harmonized with the Comic World theme.
  - **Lab & Developer Information:** Developer address and registration details in the footer.
